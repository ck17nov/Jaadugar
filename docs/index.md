# Jaadugar

Jaadugar is a personal tool that researches, writes, produces and publishes
short videos to **its operator's own YouTube channels**. One person runs it,
for their own channels, on their own server.

It is not a product, not a service for other people, and is not distributed
through any app store. There are no user accounts and nothing to sign up for.

## What it does

* Researches a topic using publicly available YouTube data.
* Takes a script from a curated bank the operator supplies, or writes one.
* Generates illustrations, synthesises narration, and renders a video.
* Runs the result through quality, originality and child-safety checks.
* Uploads it to the operator's channel, with a Made-for-Kids declaration
  where the content is child-directed.

## Cost and design

It runs entirely on free tiers — a free-forever cloud instance, free LLM and
image APIs, and open-source tooling — which is the constraint the whole
design is built around.
